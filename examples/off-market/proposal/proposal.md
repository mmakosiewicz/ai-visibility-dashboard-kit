## How to read this

- **Topics** group questions people would ask for the same reason. An AI model proposed them; a person should check them.
- **Question types** decide what can be measured. On a general question AI rarely recommends anyone, so the useful measure there is whether Sorriso Lisboa's website is used as a source.
- **Calculations** show the metric's standard name, what it divides by what, and the sample's counts. The part after “÷” says which answers the percentage is out of.
- **Labels:** *Worth tracking* = enough answers each week to see real changes. *Track only as a starting point* = Sorriso Lisboa doesn't appear yet, so it reads 0%. *Too little data*, *Nothing to measure*, *Can't measure yet* = skip.
